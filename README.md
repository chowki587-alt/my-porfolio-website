# Majid Ali — Portfolio website

A five-page responsive portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Project structure
- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Projects
- `contact.html` — Contact
- `css/style.css` — Shared styling and responsive layouts
- `js/main.js` — Mobile navigation, reveal animations, contact form
- `assets/majid-ali.jpg` — Your supplied portrait

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `js/main.js` with your real email address.
2. Update the email and profile links in `contact.html`.
3. Replace project placeholders in `projects.html` with real projects, screenshots, source-code links and live demos.
4. Review the skills page and remove anything you have not started learning.
5. Test on a phone and desktop before deployment.

## Contact form note
The form uses the visitor's email application via `mailto:`. It does not send or store messages on a server. A backend or form service is needed for direct website submissions.

## Fonts
The stylesheet imports DM Sans, Manrope and DM Mono from Google Fonts. If unavailable, local system fallbacks are used.
